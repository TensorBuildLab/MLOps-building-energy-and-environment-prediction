# Generalize with agents, guarantee with guardrails: an MLOps framework for data-driven prediction of any target in real buildings

*Draft, version 2 of the work first reported in arXiv:2407.03469. The author list is to be finalized by the authors.*

**Keywords:** building energy; indoor environmental quality; occupancy; machine learning operations (MLOps); large language model agents; data quality; time-series evaluation

## Highlights

- An LLM agent handles messy building data; domain guardrails make its results trustworthy.
- One framework for any numeric or yes/no target: energy, temperature, CO2, humidity, occupancy.
- Covers the full MLOps lifecycle, checked against all nine principles of a published definition.
- Tested on real buildings in three countries, with every agent decision on record.
- Random splits overstate accuracy on real building data; gates refuse models that cannot beat persistence.
