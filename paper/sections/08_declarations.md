# Data availability {-}

All code (the bemlops package, version 0.2.0), configurations, case-study scripts, result tables, the run record behind every reported number, the pilot prompts and the pilot deliverables are available at https://github.com/TensorBuildLab/MLOps-building-energy-and-environment-prediction under the BSD 3-Clause licence.
