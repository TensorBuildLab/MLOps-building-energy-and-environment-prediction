# Declaration of competing interest: how to create it

Elsevier journals ask the corresponding author to create the declaration with Elsevier's online tool
(https://declarations.elsevier.com/), which produces a .docx file to upload at the "Attach Files" step.
Do not convert that .docx to another format. The manuscript already contains the statement
"The author declares no known competing financial interests or personal relationships that could have
appeared to influence the work reported in this paper." Use the same answer in the tool, after confirming it
with every author.
