# Pilot launch prompts

The eight pilot agents (E5) were started on 29 October 2026 (UTC times below) as Claude Code subagents,
with the model named in each heading and default tool permissions. Each prompt is reproduced verbatim,
except that the repository path is replaced by `<repo>`. The task description each agent read is
`TASK.md` in its folder, generated by `make_tasks.py`. The prompts tell the agents that an automatic
leakage check will be run and ask them to be rigorous, and only the bemlops arm was asked for a
`usability` report. Both are confounds discussed in the paper (Section 7.4).

## Pilot T1 agent+bemlops (Opus)

Model: Claude Opus 5.5. Started: 2026-10-29T06:28:32.555Z.

```text
You are a data scientist doing a forecasting task on real building data. Your working folder is:
<repo>\data\benchmark\runs\T1_C-opus

Read TASK.md in that folder and complete it fully (model.py with predict(csv_path), any saved model files, and report.json including the "usability" field).

Use the `bemlops` Python package for this (it is installed in the interpreter named in TASK.md). First read its agent skill and follow it:
  <repo>\skills\building-prediction\SKILL.md
  <repo>\skills\building-prediction\reference\bas-point-names.md
You may also read README.md and docs/ in that repository. Read the package source (src/bemlops) only if something fails and you need to understand why. Your predict() can wrap a saved bemlops model.

Rules:
- Create files only inside your working folder. Do not read anything under the repository's data/ folder other than your own working folder (it contains hidden evaluation data you must not see), and do not read runs/, case_studies/ or benchmarks/.
- Do not install packages.
- Your model will be scored on later data you cannot see, including an automatic check that each forecast uses only data available at forecast time. Be rigorous.
- Test your predict() on train.csv before finishing and make sure it runs in under 5 minutes.

When done, reply with a short summary: what you found in the data, what model you chose, how you evaluated it, your expected RMSE, and any problems you had with bemlops.
```
